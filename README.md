# MIDI Visualizer

This visualizer takes in a MIDI file and outputs a video. In order to use video generation, you have to install FFMPEG. The video looks like a piano roll you might see on YouTube. It supports many different config options; example midiconfig.*.json files are in the repo root.

Here are some examples of its output:
- [Turkish March Rock](https://youtu.be/PZwgDSL2M8Q) has multiple instruments, bezier curves, and drum pads.
- [Remy](https://youtu.be/ZvNwbduwidQ) gradually changes the top-down bars' colors.
- [Streetlights](https://youtu.be/-WMEtLP4K-0) uses liquid drops that accelerate as they fall.
