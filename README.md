# MIDI Visualizer

This visualizer takes in a MIDI file and outputs a video. In order to use video generation, you have to install FFMPEG. The video looks like a piano roll you might see on YouTube.

Here are some examples of its output:
- [Turkish March Rock](https://youtu.be/PZwgDSL2M8Q)
- [Remy](https://youtu.be/ZvNwbduwidQ)
- [Streetlights](https://youtu.be/-WMEtLP4K-0)
